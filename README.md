# 夫のヒミツ、追跡中。

スマートブラックの広告ドラマ。選択によって夫の一日の見え方や会話が変わり、商品記事へ続きます。人物・物語はフィクションです。

## ローカルで開く

このフォルダーで静的HTTPサーバーを起動してください。Python 3の例：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで http://127.0.0.1:8000/ を開きます。ES Modulesを使用しているため、HTMLの直接ダブルクリックではなくHTTP経由で開いてください。ビルドやnpmインストールは不要です。

## GitHub Pages

ファイル一式をリポジトリ直下へ配置し、Settings → Pagesで公開ブランチの / (root) を指定します。CSS・JavaScript・画像は相対パスで参照しているため、プロジェクトのサブパスでも動作します。

## 構成

- index.html：ゲーム画面・商品記事
- app.js：画面描画・文字送り・操作
- engine.js：会話と分岐
- style.css：画面スタイル
- assets/：使用画像
- favicon.svg / .nojekyll：静的配信用設定

思い出の解放状態は同じブラウザーのlocalStorageに保存します。フォーム入力や注文処理はありません。購入ボタンは公式記事へ移動します。
